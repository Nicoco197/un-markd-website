# Unmarkd

Official website for Unmarkd

## Website

https://unmarkd.com.au

## About

Unmarkd is a digital brand and business project focused on creating a simple, modern online experience for its customers.

This repository contains the files used to host and maintain the Unmarkd website.

## Tech Stack

- HTML
- CSS
- JavaScript
- GitHub Pages
- Custom domain: unmarkd.com.au

## Project Structure

/
├── index.html
├── CNAME
├── README.md
└── assets/
    └── ...

> The exact files and folders may change as the website is updated.

## Deployment

The website is hosted using GitHub Pages and connected to the custom Unmarkd domain.

Changes pushed to the repository can be deployed through the repository’s GitHub Pages configuration.

## Development

To work on the website locally:

1. Clone or download the repository.
2. Open index.html in a browser, or use a local development server.
3. Make your changes. 
4. Test the website on desktop and mobile.
5. Commit and push the changes to GitHub.

## Domain

The production website is:

https://unmarkd\.com\.au

The `CNAME` file is used by GitHub Pages to connect the repository to the custom domain.
